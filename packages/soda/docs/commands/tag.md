### sd tag

#### sd tag add <id> <tags...>
Positionals: node ID (required), one or more tag names

Example:
```sh
sd tag add 01KNBXBK8E topic:auth review
```

#### sd tag remove <id> <tags...>
Positionals: node ID (required), one or more tag names

Example:
```sh
sd tag remove 01KNBXBK8E review
```
